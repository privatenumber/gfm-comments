# Block phase

The block phase ports cmark-gfm's block parser. It reads the source line by line, keeps the stack of open containers and one open leaf block, and reports the text blocks, HTML block lines, table cells, and generated block markup that later phases read. This file covers what it reports and how it drops reference definitions.

## What the phase reports

**Block phase** ([block/](../../src/block/index.ts)). A port of `check_open_blocks`, `open_new_blocks`, and `add_text_to_container` in [`blocks.c`](https://github.com/github/cmark-gfm/blob/0.29.0.gfm.13/src/blocks.c#L1044-L1518), plus the table extension. It keeps only the stack of open containers and the open leaf block, and reports the text of each paragraph, heading, and table cell, each line of each HTML block, and generated thematic breaks and code blocks. It also opens [footnote definitions](./footnotes.md#footnotes) as containers. Like the table extension, it trims each cell and removes the backslash of each `\|` before the inline phase reads the cell, and does the same to a paragraph whose last line becomes a table's header row ([`unescape_pipes`](https://github.com/github/cmark-gfm/blob/0.29.0.gfm.13/extensions/table.c#L150-L168), [cells](https://github.com/github/cmark-gfm/blob/0.29.0.gfm.13/extensions/table.c#L213-L228), [paragraph](https://github.com/github/cmark-gfm/blob/0.29.0.gfm.13/extensions/table.c#L283-L295)). `joinText` records each removed position, so offsets in that text still map back to the source. Without this, `[r\|s]` in a cell would match the definition `[r\|s]`, while GitHub looks up `r|s`. Code block content cannot itself contain a rendered comment, but its escaped output can change an HTML state opened earlier. `index.ts` holds the parser state and the line loop. The scanners whose result depends only on the current line take the source, a position, and the line end, and live beside it: [block starts](../../src/block/block-starts.ts), [HTML block starts and ends](../../src/block/html-block.ts), and [table rows](../../src/block/table.ts).

## Reference definitions

[references/definition.ts](../../src/references/definition.ts) ports `cmark_parse_reference_inline`, and [references/label.ts](../../src/references/label.ts) scans and normalizes the labels that definitions, links, and images share. The block phase drops link reference definitions from the start of a paragraph when it closes, and before a setext underline turns it into a heading, as `resolve_reference_link_definitions` does. A definition renders nothing, so a comment inside one is not a comment.
